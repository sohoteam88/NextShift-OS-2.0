# @nextshift/decision-brain

Decision judgment package for NextShift OS.

## Responsibilities

- Generate recommendations.
- Coordinate decision reasoning.
- Define ports for Recommendation, Strategy, Opportunity, Risk, Prioritization, and Conversation engines.

## Non-responsibilities

- Does not own business truth.
- Does not execute workflows.
- Does not store Business Memory.
- Does not access database directly.
- Does not implement real recommendation logic yet.

## Architecture Rule

Business Brain understands the business.

Decision Brain determines what should happen next.
