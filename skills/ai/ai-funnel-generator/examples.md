# AI Funnel Generator Examples

## Example 1: Generate Complete Lead Magnet Funnel

**Input:** "Generate a health quiz funnel for weight management leads in Malaysia. Target: 30-45 year old women."

**Expected output:**

AI generates:
1. Quiz title: "你的体重管理类型是什么？3 分钟测试"
2. 5 quiz questions with scoring logic
3. 3 result types (需要营养调整 / 需要运动计划 / 需要全面指导)
4. Landing page copy: hero ("3 分钟找到适合你的健康方案"), pain, mechanism, CTA
5. Thank-you page with WhatsApp CTA
6. 3-message WhatsApp follow-up per result type

Review flow: user sees all generated assets → edits → approves → publishes.

## Example 2: Landing Page Copy Only

**Input:** "Generate landing page copy for my free consultation offer. Audience: busy professionals wanting to lose 5-10kg."

**Expected output:** Hero section (headline + subheadline + CTA), Pain section (3 pain points), Mechanism ("为什么普通减肥法对忙碌的上班族无效"), Offer (free 30-min consultation + what they'll get), Social proof placeholder, CTA ("WhatsApp 预约"), FAQ (5 questions).

## When NOT to Use This Skill

- User needs **funnel strategy** (which type, sequencing, message architecture) → use `growth/funnel-builder`
- User needs **conversion audit** of existing funnel → use `growth/conversion-optimizer`
