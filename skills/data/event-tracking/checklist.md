# Event Tracking Checklist

- [ ] Naming convention consistent (entity.past_tense_action)
- [ ] Required properties specified per event
- [ ] Event type classified (Conversion/Activity/System/Error)
- [ ] Conversion events clearly marked
- [ ] All events include tenant_id, user_id, timestamp
- [ ] No PII in event properties (no names, emails in events)
- [ ] Implementation notes for frontend vs backend tracking
