# @nextshift/learning-system

Learning and improvement package for NextShift OS.

## Responsibilities

- Record learning.
- Define ports for measurement, reflection, learning, optimization, AI Coach, and feedback.
- Convert execution outcomes into future business intelligence.

## Non-responsibilities

- Does not execute workflows.
- Does not generate recommendations.
- Does not own business truth.
- Does not access database directly.
- Does not implement analytics, reflection, or AI Coach logic yet.
- Does not depend directly on Decision Brain.

## Architecture Rule

Execution produces outcomes.

Learning System turns outcomes into improved future intelligence.
