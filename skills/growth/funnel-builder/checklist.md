# Funnel Builder Checklist

Before finishing a `funnel-builder` task, check:

- [ ] Headline is ≤ 2 lines
- [ ] Every screen/section has a CTA
- [ ] Social proof is included (or placeholder recommended if none exists)
- [ ] Distractions minimized (no competing nav, secondary CTAs removed)
- [ ] Landing page has: Hero, Pain, Mechanism, Offer, CTA, FAQ sections
- [ ] Big Idea and Unique Mechanism are clearly defined
- [ ] Follow-up sequence connects each funnel stage to the next
- [ ] Mobile-first layout considered
- [ ] No exaggerated claims, fake urgency, or manipulative pressure
- [ ] Written in user's language
- [ ] References `docs/architecture/11_FUNNEL_ARCHITECTURE.md` for technical specs
