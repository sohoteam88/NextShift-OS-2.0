# 用户文案术语表

| 用户语言 | 内部术语 / 旧称 | 使用规则 |
| --- | --- | --- |
| AI 教练 | AI COO | 面向用户的标题、按钮、提示和 AI 自称统一使用。 |
| 引流资源 | Lead Magnet、引流磁铁 | 所有用户可见页面和文案统一使用。 |
| 行动按钮 | CTA | 不向用户展示缩写；用具体动作，例如“开始创建”。 |
| 成长路线 | Journey | 用户界面使用“成长路线”；代码路由保留 `journey`。 |
| 潜在客户 | Lead | 用户文案使用完整中文名称。 |

内部字段名（例如 `leadMagnet.exists`、`facebook.cta`）不得直接显示给用户；必须先映射为说明性文案。
