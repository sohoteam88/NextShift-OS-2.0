## Canonical Standards

### STD-001 Engineering Workflow

### STD-002 AI Role Framework

Defines durable execution roles, assigned agents, responsibilities, and separation of duties.

Canonical document: [STD-002 AI Role Framework v1.0](../../STD-002_AI_ROLE_FRAMEWORK_v1.0.md)

Canonical document: [STD-003 Documentation Standard v1.0](../../STD-003_DOCUMENTATION_STANDARD_v1.0.md)
