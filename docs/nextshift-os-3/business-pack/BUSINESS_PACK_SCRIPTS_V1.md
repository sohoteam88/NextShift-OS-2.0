# 第零章 · 合规规则

**这一章优先于全书任何一句话。任何话术与本章冲突，以本章为准。**

## 0.1 目的地分级（决定一句话能不能说）

同一个信息，在不同场合规则不同：

| 目的地 | 价格 | 体重数字 | 收入数字 | 品牌名 |
|---|---|---|---|---|
| **公开面**（帖子/落地页/引流资源/广告/bio） | ❌ | ❌ | ❌ | ❌ |
| **Webinar**（全团队共用，视同公开） | ❌ | ❌ | ❌ | ✅ 主动坦白 |
| **私聊**（WhatsApp/一对一） | ✅ | ✅ 须带五件套框架 | ❌ **任何场合都不可** | ✅ |

**收入数字是唯一一条在所有场合都禁止的。** 包括主讲人自己的收入、嘉宾的收入、团队任何人的收入、以及"几个月回本"这类变相承诺。

## 0.2 永远不能说的话

```
❌ 保证赚钱 / 一定有成果 / 肯定可以
❌ 任何具体收入金额（自己的、嘉宾的、别人的都不行）
❌ 「X 个月回本」「X 个月看到成果」等时间承诺
❌ 「这不是直销」（必须诚实说明）
❌ 「你不加入会后悔」（压迫式）
❌ 「现在不加入名额就没了」（假稀缺）
❌ 治 / 治愈 / 根治 / 降三高 等医疗宣称
❌ 公开面出现「瘦 X 公斤」类体重数字承诺
```

## 0.3 必须说的话

- 投资相关话题之前，必须先出现 **「我没有办法保证你一定会成功」**
- 品牌相关话题，主动坦白，不等对方问出来
- 产品类内容带官方免责：「这些产品非用于诊断、治疗、治愈或预防任何疾病。」

## 0.4 允许的措辞模式

产品功能一律用：**促进 / 帮助 / 支持 / 维持 / 有助于** + 功能
例：「促进健康的消化系统」「维持健康的体重管理」

个人体验只讲主观感受：**「我的体力跟精神有改善」**（不讲数字、不讲疗效、不代表他人）

## 0.5 体重数字五件套（仅限私聊，五件缺一不可）

Steven 原话：
> "通常一个月可以瘦 3-5 公斤，如果有其他健康问题例如荷尔蒙失调或者使用着医生的药物者可能会瘦得比较慢，因为 Herbalife 不是瘦身药物，他只是均衡营养食品，会先帮你调理体质才可以健康的瘦下来（产品有 30 天满意保证）"

必备五件：
1. 典型范围（「通常」，不说「保证」）
2. 个体差异声明（健康状况／服药者较慢）
3. 产品定位切割（不是药物，是均衡营养食品）
4. 调理体质逻辑（先调理才健康瘦）
5. 满意保证兜底（30 天）

**公开面一律不可用此框架，检测到体重数字即拒绝重写。**

# 第一章 · 教练哲学三基石

**生成任何内容、话术、引导文案，违背任一基石即不像 Steven。**

### 一、万事先调理
减重先调理体质、增重先调理肠胃——**不承诺直达结果**。

### 二、低压给台阶
「不保证成功」「看不懂就当一场误会」「不想打扰到你」——**压力永远最低，筛认真度**。

### 三、以独立为终点
Steven 原话：「她始终有一天也是要自己独立的，只是逐步开始带着她走而已」——**陪驾不代驾，能力逐步移交**。

---

**校验方法**：任何一句让对方感到被追、被逼、不好意思拒绝的话，都不像 Steven。

# 第二章 · 跟进状态机

系统据此判断「今天该跟谁、说哪句话」。用户看不到这张表，只看到今天要做的事。

| # | 状态 | 进入条件 | 出口 |
|---|---|---|---|
| 1 | 刚留资料·未触达 | 漏斗表单提交 | → 2 |
| 2 | 已首触·等回复 | 首触讯息发出 | 回复 → 3；72h 无回应 → 三选项 |
| 3 | 已回复·已发链接 | 对方回应，webinar 链接发出 | 按播放进度 → 4/5/6 |
| 4 | 看了一半 | 播放进度 20-80% | 按卡点分支处理 |
| 5 | 看完·未表态 | 播放进度 ≥ 80% | → 6 或 7 |
| 6 | 异议处理中 | 对方提出疑问 | → 7 / 9 / 10 |
| 7 | 说要考虑 | 对方说「我考虑一下」 | → 9 / 10 / 8 |
| 8 | 暂时不方便·休眠 | 选了三选项第 2 项 | 到期唤醒 → 2 |
| 9 | 已加入·等收货 | 成交 | → 新人首周 |
| 10 | 没兴趣·关闭 | 明确拒绝 | 终态 |

## 2.1 播放进度 → 卡点判断（webinar 分段对照）

Steven 实测的三个流失点，对应 webinar 三个时间区间：

| 停在 | 推断原因 | 用哪套话术 |
|---|---|---|
| < 2 分钟 | 网络不好 / 随手点开没空看 | **不是抗拒** → 重发链接 |
| 第 3 段（约 5-7 分） | 品牌抗拒（看到 Herbalife） | 品牌披露 + 信任四证 |
| 第 7 段（约 22-26 分） | 钱 / 怕被骗 | 零压力邀请 + 30 天保证 |
| ≥ 80% 未表态 | 在权衡 | 「你考虑的点是什么」 |

> ⚠️ **录制后必须回填真实分钟数**。填错则系统会对错的人说错的话。

## 2.2 回复节奏规则（系统提醒依据）

| 情况 | 系统提醒时机 |
|---|---|
| 对方主动来问 | 30 分钟内提醒回复 |
| 发完链接无反应 | 1 小时后提醒 |
| 首触后无回应 | 72 小时提醒发三选项 |
| 对方说「再想想」 | 2-3 天后提醒 |
| 完全消失 | 第 3 天、第 5 天各提醒一次 |
| 第 5 天仍无回应 | 转长线，每 2 周一次 |
| 休眠名单 | 到对方指定日期自动唤醒 |

# 第三章 · 跟进话术

## 3.1 首触（状态 1 → 2）

**Steven 原话：**
> "你好，我是 Steven。我有看到你留下资料想要了解更多关于在家创业系统／减重，想要知道一下你大概什么时候方便？"

**结构**：①自报姓名（真人感）→ ②回指对方的主动行为（消解被推销的戒备）→ ③按轨道填变量 → ④只约时间不卖货

**变量**：`{名字}` `{轨道词}`（招募＝在家创业系统／零售＝减重）
**红线**：首触绝不含价格、产品细节、品牌名

---

## 3.2 首触后 72 小时无回应 · 三选项 ⭐

**Steven 原话：**
> "我想确认一下留下资料的是本人吗？因为如果你是认真想要了解的话我们可以安排个时间。如果不是的话我也不想打扰到你。谢谢🙏"

**接着给三个选择：**
```
1  没兴趣，不想了解了
2  想了解，但目前实在太忙，请在以下时间再与我联系 →（回我一个大概日期就好）
3  我是认真的，请你给我了解更多
```

**为什么这是全套话术里最聪明的装置**：给台阶 + 筛认真度 + 把「不回复」变成「必须选一个」。针对马来西亚人不好意思直接拒绝的文化——**引导果断拒绝，以免浪费双方时间**（Steven 原述）。

**系统行为**：选 2 时要求填日期 → 存入休眠 → 到期自动提醒「X 个月前 XX 说这时候再找他，今天到期了」

**可复用场景**：看完没表态卡住、考虑多日无下文、约了没出现——**任何卡住的状态都可以甩这三个选项**。

---

## 3.3 看了一半 · 三种卡点

### (a) 停在 2 分钟以内 —— 不是抗拒
```
链接有没有打不开？我重发一次，你有空慢慢看就好 😊
```
> ⚠️ 此状态**禁止使用异议话术**——他根本没听到内容，谈异议会让他莫名其妙。

### (b) 停在品牌段（约 5-7 分）—— 品牌抗拒

**Steven 的披露原话（一对一版）：**
> "我们就是 Herbalife，你之前有听过吗？" → 答有 → "那你有用过吗？" → 答没有 → "没问题，等下我会让你了解更多"

**WhatsApp 改写版：**
```
看到你有开始了解了 👍

我猜可能是看到公司名字的时候有点犹豫？
这很正常，很多人第一次听到都会。

我做了二十年，可以跟你讲我看到的是什么——
这家公司在市场超过 40 年，纽约证券交易所上市，
超过 90 个国家通过当地卫生部检验合法经营，
背后还有一整个医学团队把关。

这些你现在就可以自己查，我当年也是这样做的。

你之前有听过这个牌子吗？
```

**信任四证（记住这四个，公开面也可用，不含品牌名）**：
40 年历史 / NYSE 上市 / 90 国卫生部检验 / 医学团队把关

### (c) 停在投资段（约 22-26 分）—— 钱 / 怕被骗

**Steven 的零压力邀请原话：**
> "没有保证你一定会成功，你可以先了解看看，看得懂是一个机会，看不懂就当一场误会。"

**WhatsApp 版：**
```
看到你有看到后面了 👍

如果是卡在「要出一笔钱」这件事——我完全理解，我当年也是。

我那时候心里想的是：最多给你骗掉这笔钱。
但如果这真的是一个机会呢？那结局就完全不一样了。

我也是正常人，我也会怕被骗。

有件事我当年不知道的：产品有 30 天满意保证。

还是那句——没有保证你一定会成功。
你可以先了解看看，看得懂是一个机会，看不懂就当一场误会。
```

---

## 3.4 看完未表态 / 说要考虑（状态 5、7）⭐ 已按 Fable 建议切一刀

**Steven 原话 + 2026-07-29 新增分辨句：**
```
你当然可以考虑，重点是你考虑的点是什么？

如果是金钱上的考虑，我当然帮不到你。
不过我想确认一下——是暂时真的调不出来，还是你还不确定这个值不值得？
前者我尊重，后者我可以跟你讲清楚，以免因为不了解而白白失去一个机会。
```

**为什么要切这一刀**：「金钱考虑」其实是两种人——真的没预算（该放手）和不确定值不值（还没看到价值，可以处理）。原版把两种人一起挡在门外。切开之后仍然守住哲学：不追没钱的人，但不放弃还没看懂的人。

## 3.6 放手（状态 10）

**触发**：对方明确表明没兴趣

**Steven 原述的判断依据**：
> 马来西亚人有个文化不够果断拒绝，所以如果没兴趣或不认真要**引导果断拒绝**，以免浪费大家的时间。

```
好的，完全没问题 😊
谢谢你跟我讲清楚，我不会再打扰你。

如果以后有需要，随时可以找我。祝你一切顺利 🙏
```

> **原则**：放手要干净。不留钩子、不说「你再想想」、不三个月后又突然冒出来。**低压给台阶的最后一步，是真的让他走。**

# 第四章 · 异议库 15 条

> 使用说明：不要背稿，理解逻辑后用自己的话说。
> 统一结构：**承认 → 反转 → 事实／类比 → 用问题收尾把主动权交回去**

## 4.1 零售轨

### 「会不会有副作用？」（高频）
**Steven 原话：**
> "当然会有副作用，就是让你变美变漂亮！产品已经在市场超过 40 年了，而且是在 NYSE 证券交易所上市。超过 90 个国家都通过当地的卫生部检验合法经营，背后还有一班医学团队帮你把关。关键在于你有没有认真使用产品而已。"

结构：①幽默反转卸防 → ②信任四证 → ③责任回归用户
> ⚠️ 幽默句可保留；**生成变体不得延伸出任何具体疗效承诺**。

### 「好贵哦」（高频）
**Steven 原话：**
> "贵的定义取决于个人，如果一样东西只是卖你 RM10 不过是完全没有效或者有安全隐患。那你觉得贵还是便宜？"

结构：价值重构 + 反问收尾
> 可延伸日均成本对比（一杯奶茶钱），**但不得承诺「一定有效」**。

## 4.2 招募轨 · 关于钱与信任

### 「是不是传销？」（高频）
**Steven 原话（首选，比长版有力）：**
> "传销是违法的，我们是一家直销公司，你会排斥直销吗？如果这个事业可以透过自己的努力改善你目前的生活状况，你还会在意他是否是直销吗？"

结构：①正名切割 → ②反问对方立场（把审判变对话）→ ③利益重构
> ⚠️ 第③句止步于「透过自己的努力改善生活状况」——**努力前置、不承诺结果**，这是合规说法的样板。

**补充事实弹药**（对方要细节时才用）：
- 非法传销的特征是收入主要来自招募费用而非产品销售
- 马来西亚直销法规定合法直销必须以产品销售为收入基础
- NYSE 上市，代码 HLF，任何人可查
- 「直销行业里确实有不好的公司，所以你的谨慎是对的。但谨慎和了解，是两回事。」

你不需要今天就相信我，你只需要给自己一个了解清楚的机会。

谢谢你的坦诚。

你不应该信任我——至少现在不应该。
我们才刚认识，我说的任何话，你都应该保持合理的怀疑。这是正确的态度。

## 4.3 招募轨 · 关于时间与能力

### 「我完全不懂社交媒体，可以做吗？」
```
这个顾虑我太理解了——我刚开始的时候也不懂怎么写文案，也不知道发什么。

但我想问你一件事：你现在有没有在用 Facebook 或者 WhatsApp？
有的话，最基本的条件你已经有了。

我们这边：
内容你不用自己想，系统写好给你，你复制贴上就行。
每一步做什么都有清楚的步骤，不是叫你自己摸索。

不懂没关系，学就好。问题从来不是起点，是你愿不愿意开始。

你最担心的是哪一部分？
```
> ⚠️ **不要用「AI」「自动化」「工具」当卖点**——目标受众听到会觉得「我不会用电脑」。全部讲成结果。

### 「我每天很忙，真的有时间做吗？」
```
我相信你真的很忙，这不是借口，是事实。

建立期大概每周 5 到 8 小时，分散开来就是下班后一小时左右。
我知道一小时也不容易挤出来。

但这一小时，是在建立一个可以放大的东西，
而不是在做一个「做多少才有多少」的工作。

第一个月你花时间建立，之后它开始帮你工作。

你现在下班之后，通常怎么用那一两个小时？
```

### 「我性格内向，不擅长社交，可以做吗？」
```
这是我最喜欢回答的问题，因为答案可能跟你想的完全相反。

内向的人往往做得比外向的人好。

外向的人容易直接找人聊、推销，但这种方式现在越来越没效——
因为人们不喜欢被推销。

内向的人通常更愿意认真写东西，更愿意深度思考。

而我们这套的核心就是内容——用内容吸引对的人，让对的人主动来找你。
不需要你跟陌生人打招呼，不需要你去说服任何人。

内向，反而是优势。

你平时喜欢用文字表达吗？
```

### 「我不会卖东西 / 我脸皮薄」
```
那太好了，因为我们不是在找销售员。

第一步不是叫你去卖，是叫你自己先用。
你自己用了有感觉，讲出来的话才有说服力。

我们不需要你去说服谁，
是你分享你自己的过程，有共鸣的人自己会来问你。

你有没有试过用了什么东西觉得不错，
然后自然而然跟朋友讲？就是那种感觉。
```

## 4.4 招募轨 · 关于系统与风险

### 「这套系统人人都在用，还有效吗？」
```
全马来西亚有多少人在开餐厅？成千上万家。
但每天还是有新餐厅开业，做得好的还是大排长龙。

为什么？因为每家的厨师不同、菜单不同、位置不同——哪怕卖的都是炒饭。

系统是一样的，但用系统的「人」不一样。
你的故事是你的，你接触到的人，跟我接触到的人，可能完全不重叠。

而且真正在用系统化方式做的人，现在还是少数。
这不叫饱和，这叫早期。
```

### 「万一 Facebook 不行了怎么办？」
```
这是一个很有远见的问题。

Facebook 在马来西亚目前还是最大的平台，短期内不会消失。
但你的担心是合理的——平台确实会变。

所以我们教你建立的，不只是一个 Facebook 账号，
而是一套「用内容吸引人」的能力。
这套能力可以搬到 Instagram，可以搬到 TikTok，可以搬到任何有流量的地方。

平台是工具，信任才是资产。
就算 Facebook 明天关掉，你 WhatsApp 里的那些人，还是你的。
```

### 「上线会不会不管我？加入之后自己摸索？」
```
这个顾虑非常真实，因为这行确实有加入之后就消失的上线。

所以我直接告诉你我会怎么做：

收到货那天你一定要让我知道，我第一天会亲自带你怎么开始——
产品怎么用、怎么冲泡，我会一个一个教你。

第一个月我每个星期都会跟进你，有问题随时 WhatsApp 我。

但我也要说实话：
我能给你的是方法、方向和支持，执行还是你自己的事。
如果你不动，我没有办法替你动。

你期待什么样的支持方式？
```

### 「这只是你在帮公司打工，你才是被赚的那个」
```
这个角度很有意思，我认真回应你。

你说的部分是对的——任何系统里，都有人在帮别人建立业务。
你上班，是在帮老板建立业务。你开店进货，是在帮供应商建立业务。

这没什么问题，关键是——你自己有没有在这个过程中受益？

我卖产品，我赚零售的部分。我建立团队，我赚团队的部分。
公司提供产品和平台，他们赚他们的。
跟你在超市买东西是一样的逻辑，大家各赚各的。

问题从来不是「谁在从你身上赚」，而是「你有没有在赚」。

你觉得什么样的模式，才算不是在帮别人打工？
```

### 「我要问我老公 / 老婆」
```
应该的，这种事本来就要商量 😊

不过我想提醒你一件事：
如果你自己都还没搞清楚，你要怎么跟他解释？

不如这样——你先把该问的都问清楚，
搞明白了再去跟他讲，那时候你讲得出来，他才听得懂。

你现在还有什么想问的？
```

### 「我怕做了朋友会讨厌我」（宝妈／上班族高频）
```
我完全懂这个感觉，而且我要告诉你——这个担心是对的。

因为传统做法就是拿着产品去找朋友，做到最后朋友看到你就想躲。
那不是在做生意，那是在消耗关系。

我们的做法完全相反：
你不用去找任何人。你把内容发出去，有兴趣的人自己来问你。

你的朋友如果没兴趣，他连问都不会问，你们的关系一点都不会变。

这是我最喜欢这套方式的地方。
```

# 第五章 · 成交与新人首周

## 5.1 零售成交（assumptive close）

**Steven 原话：**
> "说真的你是认真想要得到效果的吗？那我们的奶昔有 6 种口味 chocolate, vanilla, coffee latte, Summerberry, cookies and cream, banana。你平常都是喝什么比较多，coffee？如果是 coffee 的话我建议你试试我们的 chocolate 跟 coffee latte。我就直接配一个月的配套然后收钱。"

结构：①认真度确认（让对方自己说「是」）→ ②跳过「买不买」直接进「选哪个口味」→ ③按生活习惯个性化推荐 → ④果断收单

> ⚠️ **不要问「你的预算是多少」**——那会把对话变成讨价还价。直接进「选哪个」。

## 5.4 新人首周带法（B 路径）

**收货前**：「收到了一定要让我知道」（制造期待 + 锁定触点）→ 约线上时间引导使用

**Day 1（最重要的一天）**
1. 逐个介绍拿到的每一个产品
2. 教冲泡方法 —— Steven 原话：*「很重要，要确保他做对，如果乱乱冲泡会很难喝。这样好喝才会有效果」*（好喝→坚持→效果，依从性的朴素真理）
3. 拍 before 照 —— Steven 原话：*「叫他不用担心，拍的越丑越好。因为使用产品后健康改善了会变得越来越好看。这就是活招牌」*

**Day 2**：问「开始喝了没有？味道如何？」（呼应副作用话术的「关键在于你有没有认真使用」）

**Day 4（事业路径闸门）**：Steven 原话 —— *「喝到有感觉了才会开始跟他规划下一步」*
**亲身体验有感 = 进入事业规划的前置条件**，与「我们不是寻找销售员」闭环。
