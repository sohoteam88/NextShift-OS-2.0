# System Architecture

## Overview

NextShift OS uses a modular SaaS architecture:

- Frontend: Next.js / React
- Styling: Tailwind CSS
- Backend: Next.js API routes and server services
- Database: Supabase PostgreSQL
- Auth: Supabase Auth
- AI: OpenAI / Claude-compatible AI services
- Deployment: Vercel

## Main Layers

- App UI
- API routes
- Domain services
- Supabase database
- AI workflow engine
- Analytics and reporting
- Admin control layer
