## Phase 0

Phase 0 defines the immutable foundation of NextShift OS 3.0.

Every architecture decision, AI behavior, feature, API, database schema, and user experience must align with these documents.

If any future implementation conflicts with Phase 0, Phase 0 takes precedence.

## Governance Rules

1. Architecture follows principles. Never the opposite.
2. Capabilities exist to support better business decisions. They never become the product themselves.
3. Every AI action must strengthen the Business Twin.
4. Every execution must generate learning.
5. The Business Twin is the center of the operating system. Everything else revolves around it.
6. NextShift optimizes for long-term business success, not short-term feature quantity.
7. When uncertain, choose architectural simplicity over feature complexity.
8. Every MVP 1.0 feature must map to [MVP Phase 1, Phase 2, or Phase 3](MVP_1_ALIGNMENT.md).
