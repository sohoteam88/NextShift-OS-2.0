# Funnel Builder Examples

## Example 1: Full Health Consultation Funnel

**Input:** "Build a funnel for my health coaching consultation. Target: busy professionals 30-45 who want to lose weight. Offer: free 30-min consultation."

**Expected output:** Funnel map (Lead Magnet → Landing Page → WhatsApp → Consultation), Big Idea + unique mechanism, landing page copy (hero/pain/mechanism/offer/CTA/FAQ), WhatsApp 5-message nurture sequence, consultation booking flow.

## Example 2: Lead Magnet Only

**Input:** "I need a lead magnet for my weight loss coaching. Something quick that busy moms can use."

**Expected output:** "7-Day Meal Prep Cheat Sheet for Busy Moms" — title, promise, PDF outline (7 days × breakfast/lunch/dinner), landing page opt-in copy, WhatsApp delivery message, 3-message follow-up to consultation.

## Example 3: Webinar Funnel

**Input:** "Create a webinar to sell my RM997 3-month coaching program."

**Expected output:** Webinar title, registration page copy, 60-min slide outline with teaching + pitch transition, offer stack, Q&A script, replay email sequence.

## When NOT to Use This Skill

- User needs **content strategy** → use `growth/content-engine`
- User needs **personal brand positioning** → use `growth/personal-brand`
- User needs the **AI to generate** funnel copy → use `ai/ai-funnel-generator`
