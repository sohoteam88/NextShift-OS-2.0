# EPIC 01: Mission Engine

## Goal

Guide every user to one clear next action.

## Scope

- Today's Mission
- Step-based progress
- Continue flow
- Mission completion tracking
- AI COO state validation and explainability contracts:
  - [DASH-001 AI COO First Dashboard Philosophy](../ai-coo/DASH-001_AI_COO_FIRST_DASHBOARD_PHILOSOPHY.md)
  - [DASH-003 AI COO Route Contract](../ai-coo/DASH-003_ROUTE_CONTRACT.md)
  - [COO-001A State Requirements Matrix](../ai-coo/COO-001A_STATE_REQUIREMENTS_MATRIX.md)
  - [COO-001B State Validation Engine PRD](../ai-coo/COO-001B_STATE_VALIDATION_ENGINE_PRD.md)

## Acceptance Criteria

- User sees only one primary action.
- User can continue from the last incomplete step.
- Mission progress is stored and visible.
