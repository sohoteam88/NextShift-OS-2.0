# Design System Architect Examples

## Example 1: Full Design System for NextShift Dashboard

**Input:** "Create a design system for the NextShift CRM dashboard, using shadcn/ui and Tailwind."

**Expected output:** Complete visual system with Inter font, 4px spacing scale, 3 colors (slate neutral, blue-600 primary, emerald-500 accent), 12-column grid, component catalog covering Button/Input/Badge/StatCard/LeadTable, CSS variable definitions, and responsive breakpoints.

## Example 2: Component Audit

**Input:** "Audit our current component library — we have 3 different button styles and inconsistent spacing."

**Expected output:** Inconsistency diagnosis, unified Button spec (primary/secondary/ghost/danger × sm/md/lg), spacing normalization plan, migration checklist.

## When NOT to Use This Skill

- If the user needs a **specific screen layout** (use `ux/dashboard-ux-designer` or `ux/mobile-first-designer`)
- If the user needs a **funnel page design** (use `growth/funnel-builder`)
- If the user needs an **accessibility audit** (use `ux/accessibility-auditor`)
