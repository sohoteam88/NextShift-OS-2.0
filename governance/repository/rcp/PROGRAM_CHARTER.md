# Repository Cleanup Program Charter

Program: Repository Cleanup Program v1.0
Phase: RCP-000 Program Initialization
Status: Planning
Execution Mode: Planning-only

## Purpose

This charter establishes the Repository Cleanup Program before any cleanup activity begins.

## Mission

Create a governed, auditable cleanup program that preserves repository evidence, compatibility, rollback capability, and lifecycle traceability before any repository asset is archived, moved, or deleted.

## Program Scope

Included:

- Repository cleanup governance.
- Cleanup roadmap.
- Repository lifecycle registration.
- Cleanup pilot preparation.
- Compatibility and rollback requirements.
- Archive-before-delete controls.

Excluded:

- Cleanup execution.
- Archive execution.
- File deletion.
- Runtime migration.
- Release package movement.
- Audit evidence rewrite.
- Governance rewrite.
- Commit or push.

## Governing Baselines

RCP v1.0 inherits authority from:

- Engineering OS v1.0.
- RepoOS v1.0.
- Repository Architecture Freeze v1.0.
- Repository Retention Policy.
- Cleanup Classification Standard.
- RMP Execution Framework.
- RMP-005 Legacy Repository Classification.
- RMP-006 Cleanup Pilot Planning.

## Principles

1. Safety first.
2. Archive before delete.
3. Compatibility first.
4. Rollback required.
5. Evidence preservation.
6. Governance protected.
7. Runtime excluded unless separately authorized.

## Success Criteria

RCP-000 is successful when:

- Program documents exist.
- Roadmap is registered.
- Governance principles are defined.
- Current status is recorded.
- Master index is available.
- Repository remains unchanged.
- Working tree remains clean.

## Non-Authorization

This charter does not authorize cleanup, archive movement, deletion, migration, runtime changes, commit, or push.
