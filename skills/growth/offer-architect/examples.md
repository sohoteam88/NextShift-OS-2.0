# Offer Architect Examples

## Example 1: Health Coaching Program Offer

**Input:** "I want to sell a 3-month health coaching program at RM997. Help me design an irresistible offer."

**Expected output:**

Hormozi Value Equation analysis:
- Dream Outcome: lose 5-10kg, feel energetic, fit into old clothes → HIGH
- Perceived Likelihood: with 1-on-1 coaching + weekly check-in → MEDIUM (increase with proof)
- Time Delay: 3 months (moderate) → reduce perceived delay with "Week 1 quick wins"
- Effort: need to follow meal plan + exercise → reduce with "done-for-you meal plans"

Offer stack:
```
核心: 12 周 1 对 1 健康指导 (价值 RM2,997)
赠品 1: 个性化 7 天快速启动食谱 (价值 RM297)
赠品 2: 每周进度追踪 + AI 教练提醒 (价值 RM497)
赠品 3: 私人 WhatsApp 群支持 (价值 RM197)
保障: 14 天不满意退款

总价值: RM3,988
你的投资: RM997
```

Price anchoring: show total value first, then price. Scarcity: "本月只接受 5 位新学员". Urgency: "早鸟价 RM797（限前 3 位）".

## When NOT to Use This Skill

- User needs **funnel to sell the offer** → use `growth/funnel-builder`
- User needs **brand positioning** → use `growth/personal-brand`
