# AI Workflow Engine

## Purpose

The AI Workflow Engine guides users through personal brand, content, funnel, CRM, WhatsApp, and coaching workflows.

## AI Roles

- AI Coach
- Brand Interviewer
- Content Generator
- Funnel Copy Generator
- WhatsApp Reply Assistant
- Lead Scoring Assistant
- Admin Assistant

## Workflow Pattern

1. Collect user context
2. Read relevant business data
3. Generate recommendation or asset
4. Ask user to review
5. Save approved output
6. Trigger next mission or follow-up

## Guardrails

- Never expose secrets
- Respect tenant boundaries
- Keep user data private
- Log AI usage
- Prefer review before automation for high-impact actions
