# Retention Marketer Examples

Use this skill when the user wants to improve repeat purchase, reorder, reactivation, referral, or customer lifetime value.

## Example Prompts

- Use `$retention-marketer` to create a WhatsApp follow-up system for customers after purchase.
- Use `$retention-marketer` to win back inactive customers who have not bought in 60 days.
- Use `$retention-marketer` to design a referral flow for happy customers.

## Expected Output

Follow the output format in `SKILL.md`. Keep the result practical, segmented, and ready to turn into WhatsApp, email, CRM, or dashboard workflows.
