# 第一部分 · 演算法这一课

> **这一课的用途**：不是逼她露脸，是给她判断的依据，让她自己决定。
> 语气按教练三基石：低压、给台阶、以独立为终点。
> 建议放在她第一次要拍照之前，一次性看完，之后不再重复说教。

---

## 为什么有人发了没人看？

你可能会遇到这个情况：发了几篇，只有几个朋友按赞，然后就没有了。

**这不是你的内容不好，是你还没让平台认识你。**

我用最简单的方式讲给你听，你看完就会知道该怎么拍。

---

## 平台在想什么

Facebook、Instagram、小红书这些平台，它们靠什么赚钱？**靠让人一直看下去。**

人看得越久，广告就能放得越多。

所以平台做的每一件事，都在回答一个问题：

> **「我把这条内容推给更多人，他们会不会停下来看？」**

如果会，平台就推给更多人。如果不会，你的内容就停在那里。

**所以重点不是「我的内容好不好」，是「别人会不会停下来」。**

---

## 三件事决定平台推不推你

### 一、有没有人停下来看（最重要）

平台会看：滑到你这条的人，有几个停下来了？停了多久？

一张让人多看两秒的照片，比一张精美但一眼就滑走的图有用得多。

**这就是为什么你不需要拍得很专业。**

真实的、有生活感的画面，反而更容易让人停——因为它像一个真人，不像广告。

> **对你的意思**：随手拍就好。糊一点、乱一点，没关系。

---

### 二、平台认不认得你是真人

这一条对**刚开的新号**特别重要。

平台每天要处理几百万个新账号，它必须分辨：**哪些是真人，哪些是营销号、机器人、骗子。**

它怎么分辨？看有没有真人的痕迹——

- 有没有人脸
- 有没有生活场景（家里、路上、餐桌）
- 内容像不像一个人在过日子

一个只发文字卡片、只发产品图、从来不出现人的号，平台会倾向于把它当成营销号，**推送量会被压得很低**。

> **对你的意思**：这就是为什么建议你第一周至少露脸一次。
>
> 不是要你当网红，是要让平台知道**这个号后面有一个真人**。

---

### 三、有没有人愿意回应

留言、分享、私讯——这些比按赞重要得多。

按赞太容易了，平台知道它不代表什么。但一个人愿意打字留言，代表他真的在意。

> **对你的意思**：内容里留一个问题，比讲一堆道理有用。
>
> 「你们下班后都在做什么？」比「努力的人运气不会太差」有效十倍。

---

## 所以，为什么建议你露脸？

我不会逼你。这是你的决定。

但我要诚实告诉你三件事：

**第一，不露脸也能做，只是会比较慢。**
你可以拍手、拍背影、拍你的桌子、拍窗外。这些都可以。只是平台需要更长的时间才能确认你是真人。

**第二，露脸最大的作用不是好看，是让人记得你。**
人看一百张产品图，一张都记不住。看一次你的脸，下次就认得。

而你要做的这件事，本来就是「让人先认识你，再来问你」。

**第三，你不用拍得好看。**
不用化妆、不用滤镜、不用找角度。一张笑起来清楚的日常照就够了。

**你越像真人，效果越好——这是这件事跟当网红最不一样的地方。**

---

## 一句话总结

> 平台不是在找最漂亮的内容，
> **它是在找最像真人的内容。**
>
> 而你本来就是真人——这是你最大的优势，不是你的短处。

---

## 你现在可以做的最小一步

如果你还没准备好露脸，**没关系，先从这个开始**：

拍一张有你的手的照片。手写字、手拿杯子、手在打字都可以。

**有手的画面，已经比纯图片好很多了。**

等你哪天觉得可以了，再拍脸。慢慢来。

# 第二部分 · 招募号拍摄指引

> ⚠️ **边界**：招募号不拍产品、不拍身体变化、不拍 before/after。
> 那些属于零售号（见第三部分）。理由见「开号引导 v1」第五章：**用产品效果招募是直销红线**。

## 2.1 新人第一周 · 七天可拍清单

### Day 1 ｜ 你的角落
```
拍什么：你打算用来做这件事的那个角落
        餐桌一角 / 房间的小桌子 / 车上的驾驶座都可以
怎么拍：手机放桌上，画面里有笔记本或手机
        不用整理得很干净，乱一点更真实
配文方向：我决定开始了，这就是我的"办公室"
```

### Day 2 ｜ 每天最累的那一刻
```
拍什么：等红灯的车窗外 / 下班的电梯 / 孩子睡着后的客厅 / 换班的走廊
怎么拍：手机随手拍，模糊一点没关系
配文方向：这是我每天的样子，我想换一种
```

### Day 3 ｜ 手写的一张纸
```
拍什么：一张纸，写下你想在几个月后达成的一件事
怎么拍：手机俯拍，手可以入镜，字丑没关系
配文方向：写下来才是认真的
```

### Day 4 ｜ 正在学的画面
```
拍什么：你手机或电脑上正在看的东西——课程、笔记、系统画面
怎么拍：侧拍，带一点手，不要正对屏幕拍
⚠️ 拍之前检查：画面里不能有品牌名、价格、任何数字
配文方向：今天学到一件事……
```

### Day 5 ｜ 你自己 ⭐
```
拍什么：一张自拍，或让家人帮你拍
怎么拍：不用化妆、不用滤镜、自然光下就好
配文方向：我是谁、我为什么开始

这一条最重要——第一周至少要有一次真人脸。
如果还没准备好：先拍有手的画面（见第一部分末尾），慢慢来。
```

### Day 6 ｜ 时间是怎么挤出来的
```
拍什么：时钟 / 孩子睡着后的房间 / 清晨还没亮的窗外
        任何能说明「我在这个时间做事」的画面
怎么拍：自然光或暖灯都可以，不用打光
配文方向：一天挤一小时，就这样开始
```

### Day 7 ｜ 第一周回顾
```
拍什么：这一周拍的其中三张拼在一起，或翻开的笔记本
怎么拍：三宫格或俯拍
配文方向：第一个星期我做了什么、学到什么
```

## 2.2 招募号视频版（15 秒脚本）

```
对着镜头说 15 秒，不用背稿：

「我叫 {名字}，我{原本的身份}。
　今天是我开始的第 {N} 天。
　我今天学到……（讲一件具体的小事）」

拍法：手机竖着靠在杯子上，你坐着讲，背景是家里就好
```

## 2.3 招募号长期素材方向（第一周之后）

- 为什么决定开始（她的动机）
- 今天学到什么 / 卡在哪里
- 时间怎么挤出来的
- 对「在家工作」原本的误解
- 她原本的生活状态与不满
- 她为什么相信这条路可行

# 第三部分 · 零售号拍摄指引

> 适用时机：她开了零售号之后（做起来才开）。
> Steven 本人的零售号今天就能用。

## 3.1 核心素材：早餐三步骤

官方定式给了天然的画面结构：

```
Day 1 ｜ 浓缩芦荟汁
拍什么：兑好的一杯，放窗边
怎么拍：手机俯拍或平拍，自然光
配文方向：早上第一杯，从这里开始

Day 2 ｜ 茶饮
拍什么：泡好的一杯，可以带一点热气
怎么拍：靠窗、逆光一点点会有质感
配文方向：接下来这一杯，让整个上午比较有精神

Day 3 ｜ 营养早餐（奶昔）
拍什么：摇好的一杯，旁边可以放摇杯
怎么拍：俯拍，桌面干净一点
配文方向：这就是我的早餐，三分钟搞定

Day 4 ｜ 三杯一起
拍什么：三杯排成一排
怎么拍：平拍，背景简单
配文方向：早餐三步骤，就这样而已
```

## 3.2 生活场景（比产品特写更有效）

```
✅ 出门前在餐桌喝完那一杯
✅ 办公室桌上的摇杯
✅ 车上放着的一杯
✅ 孩子在旁边，你在喝
✅ 运动前后的那一杯
```

**为什么生活场景比产品特写好**：产品特写像广告，会被滑走；有生活的画面像一个人在过日子，会让人停下来。**这跟第一部分讲的演算法是同一件事。**

## 3.3 过程见证（她自己的）

```
Day 1  ｜ before 照 —— 拍得越丑越好
       （Steven 原话：「使用产品后健康改善了会变得越来越好看，这就是活招牌」）
第 2 周 ｜ 同一个角度再拍一次
第 4 周 ｜ 同角度、同衣服、同光线，做对比
```

**拍 before 照的规矩**：
- 同一个位置、同一个角度、同样的光
- 建议早上起床后、空腹、同一套衣服
- **拍了先存着，不用马上发**

> ⚠️ **合规**：对比照可以发，但**公开面不得配任何体重数字**（「瘦了 X 公斤」一律不可）。
> 体重数字五件套框架**仅限私聊**。见「话术全集 v1」第零章 0.5。

## 3.4 零售号视频版（15 秒脚本）

```
「今天是我喝的第 {N} 天。
　我今天的感觉是……（讲主观感受，不讲数字、不讲疗效）」

拍法：手机竖着，可以边泡边讲，不用剪辑
```

## 3.5 零售号不能拍什么

```
❌ 产品标签特写（会露出品牌名）
❌ 价格标签、收据、订单截图
❌ 药盒、药品、任何医疗相关物品
❌ 别人的 before/after（除非本人明确同意）
❌ 体重秤数字
❌ 任何暗示疗效的画面（药 → 产品的对比图之类）
```

# 第四部分 · 通用规则与合规

## 4.1 拍摄基本规则（给用户看的版本）

```
✅ 自然光最好 —— 靠窗、白天、不要开顶灯
✅ 手机横竖都行，但一条内容里保持一致
✅ 手可以入镜，让画面有人味
✅ 拍糊一点没关系，真实比清晰重要
✅ 每周至少一次露脸（做不到先拍手）

❌ 不要用滤镜美颜到认不出
❌ 不要拍纯文字卡片（平台判定为低价值，推送量最低）
❌ 不要用网上下载的图
❌ 不要拍到品牌名、价格、任何数字
```

## 4.2 拍照前的三秒检查

**每一张发出去之前，看一眼画面里有没有：**

1. **品牌名**（罐子标签、包装盒、系统后台）
2. **数字**（价格、体重、收入、任何金额）
3. **别人的脸**（没同意的不要发）

**有任何一项 → 换个角度重拍，或遮掉。**

## 4.3 两轨边界速查

| | 招募号 | 零售号 |
|---|---|---|
| 产品画面 | ❌ | ✅（不拍标签） |
| 身体变化 / before after | ❌ | ✅（不配数字） |
| 早餐三步骤 | ❌ | ✅ |
| 工作角落 / 笔记 / 学习画面 | ✅ | 可选 |
| 通勤、日常疲惫场景 | ✅ | ❌ |
| 本人露脸 | ✅ | ✅ |

# 第五部分 · 系统怎么用这份文件

## 5.1 G1 内容引擎新增输出字段

每一篇生成的内容，除了文案，还要带一个 **`visual_guide`** 字段：

```json
{
  "title": "...",
  "hook": "...",
  "body": "...",
  "cta": "...",
  "hashtags": [...],
  "visual_guide": {
    "what": "拍你打算用来做这件事的那个角落",
    "how": "手机放桌上，画面里有笔记本，不用整理很干净",
    "avoid": "画面里不要有品牌名或任何数字"
  }
}
```

**三个子字段的作用：**
- `what` —— 拍什么（具体到能照做）
- `how` —— 怎么拍（光线、角度、构图）
- `avoid` —— 避开什么（合规 + 常见错误）

## 5.2 素材来源

`visual_guide` 的内容**不由模型自由发挥**，从本文件取：
- 招募轨 → 第二部分
- 零售轨 → 第三部分
- `avoid` → 第四部分 4.2 三秒检查 + 对应轨道的禁止项

**理由**：与族群痛点同一条规矩——**画面指引必须源自真实可执行的做法，不得由 AI 凭空拟**。拍不到的指引比没有指引更糟。

## 5.3 视频类内容

若生成的是视频类内容，`visual_guide` 改为 15 秒脚本形态（见 2.2 / 3.4）。

## 5.4 演算法这一课放哪里

**建议**：新人第一次要拍照之前，一次性看完。之后不再重复说教。

放置候选：
- 开号引导完成后的下一步
- 「发」这一键第一次生成内容时，配图指引旁的「为什么要这样拍？」链接
