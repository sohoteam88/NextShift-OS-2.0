# @nextshift/execution-layer

Execution orchestration package for NextShift OS.

## Responsibilities

- Execute approved decisions.
- Coordinate execution planning.
- Define ports for capability registry, execution records, and automation policies.
- Preserve strategic intent during execution.

## Non-responsibilities

- Does not generate recommendations.
- Does not own business truth.
- Does not own Business Memory.
- Does not implement CRM, WhatsApp, email, landing pages, webinar, or automation logic yet.
- Does not access database directly.
- Does not depend on Learning System.

## Architecture Rule

Decision Brain determines what should happen next.

Execution Layer executes approved decisions.
