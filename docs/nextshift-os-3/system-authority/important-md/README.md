## Purpose

This folder is the human-friendly quick lookup panel for the most important NextShift OS Markdown files.

Use it when ChatGPT, Codex, Claude, or any contributor suggests creating a new framework, playbook, standard, architecture, capability, workflow, or version. Open this folder first and check whether the suggestion already exists.

## How To Use

1. Start with [00_CANONICAL_INDEX.md](00_CANONICAL_INDEX.md).
2. Check [01_DO_NOT_DUPLICATE.md](01_DO_NOT_DUPLICATE.md) before accepting any "new v1.0" suggestion.
3. Check the relevant category file:
   - [02_ENGINEERING_AUTHORITY.md](02_ENGINEERING_AUTHORITY.md)
   - [03_PRODUCT_ARCHITECTURE_AUTHORITY.md](03_PRODUCT_ARCHITECTURE_AUTHORITY.md)
   - [04_STATUS_RELEASE_AUTHORITY.md](04_STATUS_RELEASE_AUTHORITY.md)
   - [05_CHANGE_GATES.md](05_CHANGE_GATES.md)

## Important

These files are not copies of the original authority docs.

They are quick lookup cards that point to the real source files. If you need to edit authority, edit the original file after following [Change Control](../CHANGE_CONTROL.md).
