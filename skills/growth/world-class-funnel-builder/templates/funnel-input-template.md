# Funnel Input Template

Fill in before calling the world-class-funnel-builder skill.

```
Business Type:        (e.g. health product, side income, coaching, recruitment)
Product / Service:    (specific name or description)
Target Audience:      (demographics, location, situation)
Market Location:      (e.g. Malaysia, Singapore, global)
Language:             (zh / en / ms — default: zh)
Main Customer Pain:   (the #1 problem they face every day)
Desired Result:       (what they want to achieve)
Offer Price:          (free / low-ticket / high-ticket / price range)
Funnel Goal:          (collect leads / book call / close sale / recruit)
Traffic Source:       (Facebook ads / TikTok / organic / referral)
Closing Method:       (WhatsApp / Zoom call / direct purchase / webinar)
Brand Tone:           (warm / professional / casual / motivational)
```

## Quick Fill Example — Side Income / WhatsApp Funnel

```
Business Type:        Side income opportunity
Product / Service:    Social media + AI副业系统
Target Audience:      马来西亚华人上班族和家庭主妇，25–38岁
Market Location:      Malaysia
Language:             zh
Main Customer Pain:   死薪水，每月财务压力大，存不到钱
Desired Result:       每月额外赚 RM1,000–3,000，不影响正职
Offer Price:          Free lead magnet → paid program
Funnel Goal:          Collect leads → WhatsApp close
Traffic Source:       Facebook ads, TikTok organic
Closing Method:       WhatsApp one-on-one
Brand Tone:           Warm, relatable, local
```
