# Retention System

## Mission

Keep customers active and supported after conversion through timely follow-up, value delivery, and reactivation.

## Operating Principles

- Design for CRM clarity: every lead, customer, or team member needs a clear next action.
- Keep statuses, stages, and ownership rules simple enough for new users.
- Prefer helpful automation over complex configuration.
- Include mobile-first and WhatsApp-friendly workflows when relevant.
- Make assumptions explicit when context is missing.
- Never expose API keys or private customer data.
- Write in the user's language unless they request another language.

## Step 1: Collect Context

Collect:

- customer lifecycle
- purchase/usage cycle
- retention issue
- channels
- customer segments
- churn signals
- success milestones

Ask concise questions only for missing high-impact details. If enough context exists, proceed directly and label assumptions.

## Step 2: Build CRM System

1. Define retention stages and risk signals.
2. Create post-purchase and success check-in workflows.
3. Design reorder, renewal, or next-step reminders.
4. Create dormant customer reactivation tasks.
5. Define retention metrics and dashboard fields.

## Step 3: Output

Deliver:

- retention stages
- risk signals
- follow-up workflows
- reorder reminders
- reactivation tasks
- retention metrics
- CRM automations

End with the first CRM implementation or workflow step.
