# Team Duplication Examples

## Example 1: Daily Action Playbook

**Input:** "Create a daily action plan that new team members can follow to get their first customer in 30 days."

**Expected output:**

30-Day Duplication Playbook:
- Week 1: Complete onboarding + publish 3 educational posts
- Week 2: Generate first 5 leads from content + start WhatsApp conversations
- Week 3: Book 2 consultations + convert 1 lead
- Week 4: Get first customer referral + start second content cycle

Daily actions (15 min/day): 1) Check AI Coach mission, 2) Publish 1 content piece, 3) Follow up 2 leads, 4) Log activity in CRM.

Scripts included: first WhatsApp message template, follow-up template, consultation invite template.

## When NOT to Use This Skill

- User needs **content calendar** → use `growth/content-engine`
- User needs **AI-generated scripts** → use `ai/ai-content-generator`
