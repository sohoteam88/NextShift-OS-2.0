# ADR

Architecture Decision Records capture specific architectural decisions made while evolving NextShift OS 3.0.

RFCs preserve proposal history.

ADRs preserve concise accepted decisions and their consequences.

## Rule

Use an ADR when a decision is narrow, concrete, and architectural.

Use an RFC when a decision changes core product direction, Constitution, AI behavior, Business Twin, or platform architecture.

ADR format, lifecycle, metadata, and supersession rules are defined in [Architecture Decision Record Standard](ARCHITECTURE_DECISION_RECORD_STANDARD.md).
