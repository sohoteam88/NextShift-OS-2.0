# @nextshift/capability-layer

Capability platform bootstrap package for NextShift OS.

## Responsibilities

- Define capability runtime boundaries.
- Define capability registry boundaries.
- Define capability contract boundaries.
- Define capability policy boundaries.
- Define capability result boundaries.

## Non-responsibilities

- Does not own business truth.
- Does not generate recommendations.
- Does not make strategic decisions.
- Does not learn directly.
- Does not execute workflows autonomously.
- Does not implement CRM, WhatsApp, email, landing pages, webinar, automation, traffic, revenue, or creative studio logic.
- Does not access database, API, UI, apps, or infrastructure.

## Architecture Rule

Capabilities are execution abilities.

Execution Layer coordinates capabilities.

Capabilities must not bypass approved decisions.
