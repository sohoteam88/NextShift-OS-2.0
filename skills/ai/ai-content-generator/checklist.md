# AI Content Generator Checklist

- [ ] Prompt template used (not freeform prompt)
- [ ] Variables resolved from user/tenant data
- [ ] Output language matches user's `preferred_language`
- [ ] No income claims or money guarantees in generated content
- [ ] Content tagged as `generated_by_ai: true` in database
- [ ] Usage logged (tokens in/out, cost, tenant_id)
- [ ] Tenant AI quota checked before generation
- [ ] Platform-appropriate format (Facebook long post vs TikTok script vs 小红书 note)
- [ ] CTA included and varied
- [ ] Content follows education-first principle
- [ ] References `docs/architecture/09_AI_ARCHITECTURE.md`
