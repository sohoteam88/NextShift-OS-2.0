# Dashboard V5 User Flow

## Goal

The user should know within 10 seconds:

- Where am I?
- What should I do?
- What happens next?

## Flow

### New User

1. Opens Dashboard.
2. Sees Today's Mission first.
3. Clicks Continue Mission.
4. Completes the current Journey State action.
5. Returns to Dashboard and sees progress path move forward.

Primary surfaces:

- Today's Mission
- Progress Path

Hidden or de-emphasized:

- Advanced tools
- Analytics
- AI Workforce
- Deep performance views

### Activated User

1. Opens Dashboard.
2. Sees current mission and path progress.
3. Gets one AI COO recommendation.
4. Uses Quick Access only when needed.

Unlocked tools:

- Content Engine
- Funnel Builder

### Advanced User

1. Opens Dashboard.
2. Sees mission, path, recommendation, and compact snapshot.
3. Expands Quick Access for operational tools.

Unlocked tools:

- AI Workforce
- Analytics

## Anti-Patterns Removed

- Module launcher first screen
- Multi-card KPI walls
- Large chart blocks
- Secondary recommendation lists
- Experimental widgets
- Redundant navigation
