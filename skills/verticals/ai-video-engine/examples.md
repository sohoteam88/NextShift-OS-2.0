# AI Video Engine Examples

## Example 1: Health Tip Reel

**Input:** "Create a 30-second Instagram Reel script about meal prep for busy moms. Offer: free health consultation."

**Expected output:**

Hook (3s): "你知道吗？周末花 2 小时可以解决一周的午餐问题"
Scene 1 (5s): Show fridge with 5 prepared meal containers
Scene 2 (10s): Quick-cut montage of meal prep steps
Scene 3 (7s): Talking head: "我是 [name]，帮助忙碌妈妈用最少的时间吃得健康"
CTA (5s): "想要我的 7 天食谱？点 bio link 免费领取"

Image prompt: "Organized fridge with 5 colorful meal prep containers, bright kitchen, natural lighting, top-down view"
Voice prompt: "Warm, energetic female voice, Malaysian Chinese accent, conversational tone"
Video prompt: "Quick-cut cooking montage, 2x speed, upbeat background music, text overlays for key steps"

## Example 2: Faceless Video

**Input:** "I don't want to show my face. Create a TikTok about 3 breakfast mistakes."

**Expected output:** Hook + 3 slides with text overlay + stock footage prompts + voiceover script + CTA. No face required.

## When NOT to Use This Skill

- User needs **written content** (posts, captions) → use `ai/ai-content-generator`
- User needs **content strategy** → use `growth/content-engine`
