# 第一章 · 硬规则

## 1.1 Bio 是长期挂着的公开资产

风险高于单篇帖子——帖子发错可以删，bio 写错会一直挂着，而且会被搜索、被截图、被举报。

**因此 bio 生成走加严过滤**：不只过 G4，还要过一遍「这句话如果被截图举报会怎样」的自检。

## 1.2 号名与简介的禁止项

```
❌ 品牌名（Herbalife / 康宝莱 / 贺宝芙 / 任何产品商标）
❌ 收入词（月入 / 副业收入 RM / 赚 / 被动收入）
❌ 疗效词（治 / 治愈 / 根治 / 降三高 / 排毒）
❌ 体重数字（瘦 X 公斤 / 减 X kg）
❌ 价格
❌ 「保证」「一定」「肯定」
❌ 头衔造假（新人不得自称导师、专家、营养师）
```

## 1.3 两个号必须看起来不是同一套

招募号与零售号的名字、简介、语气**不得让人一眼看出是同一个体系**。

理由：招募号不得引用零售见证（见第五章），若两号在名字层就撞脸，用户会自然地把内容混着发。**分离从名字开始。**

## 1.4 轨道用词归属

| 词 | 归属 |
|---|---|
| 在家创业系统 / 第二条路 / 多一份收入 | **招募轨专用**，零售号不得使用 |
| 健康管理方案 / 营养早餐 / 调理 / 体重管理 | **零售轨专用**，招募号不得使用 |
| 健康教练 | 零售轨 |
| 过来人 / 带路的人 / 在学的人 | 招募轨 |

# 第二章 · Steven 本人的两个号（定稿）

## 2.1 招募号 ✅ 定案

```
名字：Steven ｜ 20 年在家工作

简介：
20 年前我也是打工，在网上看到一个广告就留了名单。
现在换我带人走这条路。
不保证你会成功，但至少你试过。
```

**设计理由：**
- **「20 年」是分量**，也是这个号唯一不可复制的资产
- **「我也是从广告留名单进来的」是镜像**——观众此刻正在做同一件事，这是最强的开场
- **「不保证你会成功，但至少你试过」是 Steven 的招募母版**，合规原生：反向合规开场 + 把行动本身定义为赢

**落选方案（留档）：**
- `Steven 的第二条路` —— 好，但分量不如「20 年」
- `厂里的十年，你已经见过了` —— 钩子最强（蓝领族群母版），但只打中蓝领轮班族，宝妈与上班族无感。**保留给广告文案用，不适合当号名**

---

## 2.2 零售号 ✅ 定案

```
名字：每天一杯，慢慢变好

简介：
Steven｜健康教练
20 年只做一件事：帮人用早餐把身体调回来。
减重、增重、想更有精神，都可以问我。
```

**设计理由：**
- **「慢慢」是名字层的合规护栏**——直接把「万事先调理，不承诺直达结果」写进号名，任何人看到都不会期待速效
- **涵盖三个零售方向**（减重／增重／改善健康），不把自己框死在单一场景
- 全部方案里最不像广告的一句

**落选方案（留档）：**
- `Steven 健康教练` —— 清楚但平淡
- `Steven 的营养早餐` —— 「先调理，才谈瘦」这句很好，**建议保留为内容里的口头禅**，但当简介太硬

# 第三章 · 新人模板

> 系统自动填槽，零手工。槽位来自 Brand DNA。

## 3.1 招募号（新人第一个开的号）✅

```
名字：{名字} 的第二条路

简介：
{原本的身份}
在学怎么在家多一份收入。
边学边分享，有问题可以问我。
```

**槽位：**
- `{名字}` ← Brand DNA 姓名
- `{原本的身份}` ← O2 访谈「过去职业」主题，例：「两个孩子的妈」「上班族第 8 年」「电子厂做了 12 年」

**为什么是「在学」而不是头衔：**

新人没有成绩、没有资格教人。**「我在学，边做边分享」是她此刻唯一诚实又有吸引力的位置**——天然合规（不承诺任何东西），也天然适合她发「为什么开始 / 今天学到什么」这类内容。

这与事业包「拍 before 照，越丑越好，这就是活招牌」同一个逻辑：**她的价值不在于已经成功，在于她正在路上，而且看得见。**

**为什么不用角色化名字（「在家工作系统导师」）：**
对一个刚加入两周的人是假的，她自己心虚，别人也看得出来；而且这类名字满街都是，一看就是做直销的。

**备选（留档）：** `{名字}｜下班后` —— 直白，适合上班族，但排除了全职妈妈（她没有「下班」）。「第二条路」是三个首发族群都能用的。

---

## 3.2 零售号（她做起来之后才开的第二个号）✅

```
名字：{名字} 慢慢变好

简介：
不吃药、不挨饿，先把身体调理好。
我自己在做，把我知道的告诉你。
```

**可选加句（放进句库，让她挑）：**
> 「我不是营养师，我只是自己做了有感觉，想分享给你。」

这一句同时是**合规护栏**（主动撇清专业身份）和**亲和力来源**（同路人而非专家）。

**槽位：** `{名字}`、`{目标}`（想减重／想更有精神／想调理肠胃，来自 O2）

**落选方向（留档）：** `{名字} 的日常营养`、`{名字} 的调理日记`、`跟 {名字} 一起变健康`（后者适合宝妈，但暗示社群/带团，新人第一天撑不起来，**留给她做起来之后升级用**）

# 第四章 · 三平台规格差异

**一份 bio 不能复制到处贴。** 字数、格式、调性都不同。

| 平台 | 名字 | Bio 上限 | 链接 | 特别注意 |
|---|---|---|---|---|
| **FB 专页** | 可长，含关键词有利搜索 | 简短介绍 255 字元；「关于」可长 | 可多个 | CTA 按钮设「发送讯息」 |
| **IG** | 用户名（英数）+ 显示名（可中文） | **150 字元硬上限** | **只有一个** → 放 WhatsApp | 要断行、要留白，不能写成一整段 |
| **小红书** | 昵称 | 短 | 受限 | 调性最不同，语气要更软更口语，**不要照搬 FB** |
| **TikTok** | 昵称 | 短 | 一个 | 同 IG 思路 |
| **WhatsApp Business** | 商家名称 | 简介 + 营业时间 | — | 跟进全在这里，别漏掉设置 |

## 4.1 IG 版（150 字元内，招募号示例）

```
Steven ｜在家创业 20 年
20 年前我也是打工
现在带人走这条路
不保证成功，至少你试过
👇 想了解私讯我
```

## 4.2 IG 版（零售号示例）

```
每天一杯，慢慢变好
Steven｜健康教练
不吃药、不挨饿
先把身体调理好
👇 想问什么都可以
```

# 第五章 · 招募号内容边界（硬规则）

> **2026-07-29 Steven 明确指出，Fable 记录为硬规则。**

**招募号不得出现任何过程见证 / 产品体验 / 健康效果内容。**

| 招募号发什么 ✅ | 招募号不发什么 ❌ |
|---|---|
| 为什么决定开始（她的动机） | 喝奶昔打卡 |
| 今天学到什么 / 卡在哪里 | before / after 对比照 |
| 时间怎么挤出来的 | 身体变化、体重、精神变好 |
| 对「在家工作」原本的误解 | 任何产品名、产品照 |
| 她原本的生活状态与不满 | 客户见证 |
| 她为什么相信这条路可行 | 产品成分、功效说明 |

## 5.1 为什么这是硬规则不是建议

**用产品效果招募 = 直销合规红线。**

一个招募导向的账号，若用「我瘦了」「我精神变好了」来吸引人加入事业，等于以产品效果作为事业机会的招徕，这是合规上最典型的问题形态。

**因此：招募轨生成的内容若出现体重／健康效果类见证，应由 G4 直接拒绝并重生成。** 与「零售页不得出现创业/副业/收入词根」是同一道闸的两个方向。

## 5.2 由此产生的连带修正

**新人只有招募号的第一周，她的内容素材来自「为什么开始」和「正在学什么」，不是产品体验。**

产品体验类内容（Day 1 跟我一起喝、Day 7 我感觉如何、before 照）要等她**开了零售号才有地方发**。

> ⚠️ 这也意味着 **F-34 配图指引必须分两套**：招募号拍什么、零售号拍什么。两轨的画面语言完全不同。

# 第六章 · 开号引导流程

## 6.1 顺序

```
新人加入
  → Day 1-4 自用体验（事业包首周带法）
  → Day 4 体验闸门通过
  → 【开招募号】← 本章
  → 「发」这一键开始有用
  → （做起来之后）开零售号
```

**只开一个号，招募号。** 系统在她开零售号之前，不显示任何零售相关的东西。

理由（Steven 原述）：**这个系统主要是招募，进口之后才零售。** 而且 Day 1-4 她还在自用体验、还没有客户，本来就没有零售素材可发。

## 6.2 平台：FB 专页，不是个人号 ✅

**引导里要写明的两个理由：**
1. 个人号发商业内容容易被限流，而且朋友会觉得被打扰
2. **专页有数据**——她才看得到「这周多少人点了」，这是「投」那一键的地基

**必须提醒的一句：**
> 专页刚开是没有粉丝的。头几篇你要自己分享到个人号，让朋友先看到。
> 不然你发了没人看，会以为系统没用——其实只是还没有人知道你开了这个专页。

## 6.3 头像 ✅ 本人照片

**要求：**
- 素颜、日常、清楚就好
- **不要美颜过度、不要摆拍、不要证件照**

**理由（写进引导，让她理解而不只是照做）：**
> 你之后要发的是你正在学、正在做的过程。头像太精致，跟内容会打架，反而不可信。
> 一张笑起来清楚的日常照就够了。
