# Business Operating System Architect Checklist

Before finishing a `business-operating-system-architect` task, check:

- Growth, CRM, AI, Data, UX, and Verticals are all considered.
- The current bottleneck is identified.
- Specialist work is routed to the correct skill instead of duplicated.
- Dependencies and build order are explicit.
- MVP roadmap is realistic and phased.
- Metrics and operating cadence are included.
- No API keys, secrets, or unsafe private data are exposed.
- The final response summarizes files changed, what was added, and what still needs improvement when files were edited.
