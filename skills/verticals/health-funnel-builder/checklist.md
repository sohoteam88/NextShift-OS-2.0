# Health Funnel Builder Checklist

- [ ] No specific brand names unless user explicitly requests
- [ ] No medical claims or guaranteed health outcomes
- [ ] No before/after weight numbers presented as guarantees
- [ ] Uses lifestyle, education, and assessment language
- [ ] Health quiz has ≤ 7 questions
- [ ] Result types are helpful (not fear-based)
- [ ] WhatsApp follow-up is educational before promotional
- [ ] Consultation flow includes prep guide
- [ ] All assets include: Health Quiz, Landing Page, WhatsApp Follow-up, Consultation Flow
- [ ] Written in user's language (zh/en/ms)
