# Business Operating System Architect Examples

Use this skill when the user wants to coordinate multiple NextShift systems instead of solving one isolated task.

## Example Prompts

- Use `$business-operating-system-architect` to design the full NextShift operating system for a new user.
- Use `$business-operating-system-architect` to decide which skills should build Growth, CRM, AI, Data, UX, and Verticals.
- Use `$business-operating-system-architect` to create an MVP roadmap across all subsystems.

## Expected Output

Follow the output format in `SKILL.md`. Route specialist work to the correct skill category and make dependencies clear.
