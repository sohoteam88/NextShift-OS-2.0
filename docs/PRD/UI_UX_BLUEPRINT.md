# UI/UX Blueprint

## UX Goal

Every new user should always know:

- Where am I?
- What should I do next?
- What happens after this?

## Principles

- Mobile first
- One primary action per screen
- Progress over feature overload
- Reduce cognitive load
- Avoid empty dashboards
- Guide users through today's mission

## Core Screens

- Welcome
- AI Interview
- Choose Goal
- Generate Assets
- Today's Mission
- CRM
- Funnel Builder
- AI Coach
- Admin
