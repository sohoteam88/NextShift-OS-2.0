# Funnel Builder

## Mission

Build a complete funnel that moves a prospect from problem awareness to trust, application, and sales call using clear stages, strong messaging, and a believable unique mechanism.

## Framework

Use a blend of:

- **Russell Brunson style funnel architecture**: map the journey, sequence the pages/messages, create clear CTAs, and move the prospect step by step.
- **Todd Brown style message architecture**: identify the Big Idea, unique mechanism, market sophistication, belief shifts, problem diagnosis, and offer logic.

Do not create a random collection of pages. Build a connected conversion path where each stage prepares the prospect for the next one.

## Funnel UI Rules

Apply these as hard constraints when designing landing pages or funnel screens:

```yaml
headline:
  max_lines: 2

cta:
  every_screen: true

social_proof:
  mandatory: true

distraction:
  minimum: true
```

Interpretation:

- Keep the main headline short enough to scan in 2 lines or less.
- Every screen or major viewport must contain a clear CTA.
- Include social proof unless the user explicitly has none; if none exists, recommend safe placeholders such as credibility signals, process proof, or customer count fields to collect later.
- Remove navigation, competing links, decorative clutter, unnecessary menus, and secondary CTAs that weaken conversion.

## Funnel Path

Use this default funnel sequence:

```text
Lead Magnet
↓
Landing Page
↓
Email Sequence
↓
WhatsApp
↓
Webinar
↓
Application
↓
Sales Call
```

If the user asks for a different funnel, adapt the sequence but keep the same message logic.

## Operating Principles

- Interview before building when essential context is missing.
- Start with the audience's pain, current failed attempts, and desired transformation.
- Build around one Big Idea and one unique mechanism.
- Make each stage earn the next click, reply, registration, application, or call.
- Design around one conversion action per funnel step.
- Use proof before high-friction actions like application, payment, or booking.
- Prioritize mobile CTA visibility and sticky CTA patterns when appropriate.
- Avoid fake urgency, fake scarcity, exaggerated claims, or manipulative pressure.
- Write in the user's language unless they request another language.

## Step 1: Collect Context

Collect:

- Target audience
- Pain/problem
- Dream outcome
- Current failed solutions or alternatives
- Main offer
- Unique mechanism or method
- Proof, case studies, testimonials, or credibility
- Lead magnet idea, if any
- Webinar topic, if any
- Sales call or application goal
- Tone, language, and platform/channel constraints
- Social proof available
- Form fields required
- Device priority

Ask concise questions only for missing high-impact details. If the user gives enough context, proceed directly and flag assumptions.

## Step 2: Build Funnel Strategy

Generate:

- Audience diagnosis
- Big Idea
- Unique mechanism
- Core promise
- Belief shifts required before buying
- Funnel stage objective for each step
- CTA for each step
- Follow-up logic between stages

## Step 3: Generate Funnel Assets

For the full funnel, generate:

- Lead Magnet
- Landing Page
- Email Sequence
- WhatsApp flow
- Webinar outline
- Application questions
- Sales call positioning

## Landing Page Copy Requirements

Always generate landing page copy with these sections:

- Hero Section
- Pain Section
- Mechanism
- Offer
- CTA
- FAQ

Use this page logic:

1. **Hero Section**: name the audience, desired outcome, timeframe or path, and primary CTA.
2. **Pain Section**: describe the real frustration, failed attempts, hidden cost, and emotional stakes.
3. **Mechanism**: explain why old approaches fail and introduce the unique mechanism that changes the result.
4. **Offer**: show what they receive, how it works, who it is for, and why it is credible.
5. **CTA**: make the next action specific: download, register, message, apply, or book.
6. **FAQ**: handle fit, time, price, process, proof, risk, and next-step objections.

## Landing Page UI Requirements

When designing the funnel UI, generate:

- Headline, max 2 lines
