# UK-001 Terminology Glossary

## Purpose

This glossary is the approved terminology source for UK-001 Design Language and future UI Kit documentation.

## Terms

| Term | Definition |
| --- | --- |
| Action | A user-triggered operation that changes state, navigation, or workflow progress. |
| AI Design Agent | An AI system that generates or evaluates design artifacts using UI Kit guidance. |
| Anti-pattern | A documented design approach that should be avoided because it creates inconsistency, ambiguity, or operational risk. |
| Application | A concrete user-facing product surface assembled from platform and capability artifacts. |
| Blueprint | The product and architecture foundation that defines why NextShift exists and what principles constrain it. |
| Business Capability | A domain-specific package of workflows, rules, and behaviors that supports business operations. |
| Card | A repeated or framed item used for comparison, summary, or compact detail. |
| Component | A reusable UI building block owned by the Design System. |
| Context | The operational situation that changes what content or action is relevant. |
| Dashboard | An operational summary interface for monitoring status, progress, risk, and priority. |
| Design Language | The approved vocabulary and usage model for describing NextShift interfaces. |
| Design System | The implementation authority for tokens, components, layouts, interaction, visualization, accessibility, and theming. |
| Flow | A multi-step user journey with a start, progression, and completion state. |
| Layout | A structural arrangement of content and controls. |
| Module | A bounded functional area inside a workspace. |
| Panel | A contained operational area for focused controls or data. |
| Pattern | A reusable user experience solution. |
| Section | A logical grouping of related content within a view. |
| State | The current condition of data, UI, workflow, or system feedback. |
| UI Kit | The language and usage authority for applying the Design System consistently. |
| Variant | A documented variation of a component, pattern, or state. |
| View | A complete screen or route-level surface. |
| Widget | A reusable dashboard unit that communicates a single operational signal. |
| Workspace | A business operating area where users perform ongoing work. |

## Reserved Terms

These terms should only be used in their approved context:

| Term | Approved Context |
| --- | --- |
| Token | Design System implementation primitive. |
| Component | Design System UI building block. |
| Runtime | Application execution and integration layer. |
| Governance | Process and decision framework. |
| Capability | Business-domain workflow package. |

## Terms To Avoid

| Avoid | Preferred Replacement |
| --- | --- |
| Box | Panel, card, or section |
| Pagelet | Section or panel |
| Screen | View |
| Manage | Specific action label |
| Thing | Specific domain noun |
| Tile | Card or widget, unless fixed-format grid tile is explicitly intended |
