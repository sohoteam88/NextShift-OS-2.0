## Mission

Mission Generator V2 converts a `PriorityResult` into an executable `MissionPlan`.

It answers:

- What exactly should the user do?
- How should they do it?
- How do we know it is complete?

## Output Contract

`MissionPlan` includes:

- `id`
- `objective`
- `description`
- `steps`
- `estimatedTime`
- `successCriteria`
- `completionChecks`
- `route`
- `missionType`
- `nextMilestone`

Each `MissionStep` includes:

- `id`
- `title`
- `description`
- `estimatedMinutes`
- `required`

## Template Rule

Each `MissionType` owns a static execution template. Mission Generator selects the template from `PriorityResult.missionType`; it does not invent structure in Dashboard or Mission Authority.

Supported mission types:

- `BRAND`
- `POSITIONING`
- `CONTENT`
- `LEAD_MAGNET`
- `FUNNEL`
- `TRAFFIC`
- `CUSTOMERS`
- `RETENTION`
- `TEAM`
- `OPTIMIZATION`
- `SYSTEM`

## Completion Rule

Mission completion is validated through `completionChecks`. A mission is complete only when all checks pass.

## Dashboard Rule

Dashboard displays the mission plan generated by Mission Generator:

- objective
- description
- current step
- progress
- estimated time
- next milestone

Dashboard must not generate mission plans.

## Audit Rule

Mission decision audit metadata stores:

- mission generated event
- objective
- steps
- completion checks
- completion result

## Acceptance Criteria

- Every priority generates objective, description, steps, success criteria, completion checks, route, mission type, and next milestone.
- Mission completion is validated.
- Dashboard displays mission plan.
- Type-check passes.
- Build passes.
