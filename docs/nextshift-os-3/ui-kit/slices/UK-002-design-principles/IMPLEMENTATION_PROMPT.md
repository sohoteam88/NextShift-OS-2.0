# NextShift UI Kit v1.0

# UK-002 Implementation Prompt

**Project:** NextShift UI Kit v1.0

**Slice:** UK-002 Design Principles

**Lifecycle Phase:** Implementation

**Target:** Claude Design

**Supporting:** Codex documentation only when required

## Mission

Produce the official Design Principles documentation for the NextShift UI Kit.

The document defines the reusable principles governing every NextShift interface.

Do not redesign the Design System.

## Objectives

Create production-ready documentation describing:

- AI-first experience
- Decision-first UX
- Clarity over complexity
- Consistency
- Progressive disclosure
- Enterprise scalability
- Accessibility by default
- Human and AI collaboration
- Trustworthy interaction
- Responsive-first thinking

## Required Deliverables

Produce:

1. DESIGN_PRINCIPLES.md
2. PRINCIPLE_EXPLANATIONS.md
3. UX_FOUNDATIONS.md
4. ANTI_PATTERNS.md
5. IMPLEMENTATION_REPORT.md

## Documentation Requirements

For every principle include:

- Purpose
- Rationale
- Usage guidance
- Examples
- Anti-patterns
- Relationship to UK-001
- Relationship to Design System

## Explicit Non-Goals

Do not include:

- Component implementation
- Tokens
- React
- Vue
- CSS
- Runtime
- Storybook
- API documentation

## Completion Checklist

Implementation completes when:

- Every principle is documented.
- Anti-patterns are documented.
- AI generation guidance is included.
- Documentation is reusable.
- No Design System duplication exists.
